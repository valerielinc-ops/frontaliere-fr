Ce catalogue rassemble les plaques publiées dans le relevé cantonal vérifié. Les pages numérotées gardent la liste lisible : ouvrez une fiche pour voir le statut, le prix et l’échéance disponibles, puis vérifiez toujours la source officielle avant de vous fier à une valeur. Les lignes historiques restent visibles uniquement lorsqu’une publication officielle les rend vérifiables, et les données contradictoires sont écartées. Le nombre total décrit les fiches publiées dans ce relevé, pas une promesse de nouvelles enchères ; le catalogue ne recueille aucune donnée personnelle et ne remplace pas la publication officielle du canton. Les prix et les échéances peuvent changer après le relevé. Une fiche historique peut rester accessible après sa sortie du catalogue courant : cet index montre les lignes du relevé sans supprimer les URL déjà publiées.

Cette page rassemble les catalogues cantonaux publics. Un prix actuel est la dernière offre visible, pas une vente conclue. Les résultats finaux ne sont ajoutés à l’historique que lorsqu’une source officielle les rend vérifiables. Les noms des enchérisseurs ne sont ni collectés ni publiés.
