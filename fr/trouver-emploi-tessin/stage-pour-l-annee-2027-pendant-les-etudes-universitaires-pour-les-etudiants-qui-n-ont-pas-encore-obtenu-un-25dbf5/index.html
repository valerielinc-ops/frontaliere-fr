il offre la possibilité de réaliser des stages pour l'année 2027 pendant les études universitaires pour les étudiants qui n'ont pas encore obtenu un baccalauréat ou une maîtrise en psychologie, dans les structures suivantes de l'OSC compatible avec la disponibilité : Service psychosocial (SPS) pour adultes, Lugano Viganello Clinique psychiatrique cantonale (CPC), Mendrisio Centres psychoéducatifs (CPE), Stabio, Lugano et Gerra Piano

Laboratoire de psychopathologie de travail, Lugano Viganello Annexe Directive sur les salaires des agents auxiliaires en vigueur
