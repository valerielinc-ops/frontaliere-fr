Kantonale Verwaltung Basel-Landschaft compte actuellement 68 postes ouverts publiés sur Frontaliere Ticino, répartis dans 1 canton suisse. Tous les postes sont concentrés dans le canton de BL (65 offres). Par ville, les sites avec le plus de postes ouverts sont Liestal (24 offres), suivi de Muttenz (5), Birsfelden (3), Therwil (3), Waldenburg (3), Münchenstein (2). Le salaire médian estimé pour ces postes est de CHF 105'500 brut par an. Au cours des 28 derniers jours, 65 nouvelles annonces ont été publiées. Tous les postes actifs sont en temps plein. Les salaires publiés pour ces postes vont de CHF 44'500 à CHF 166'000 brut par an. Parcourez les postes actifs ci-dessous et postulez directement sur le site de l’employeur.
