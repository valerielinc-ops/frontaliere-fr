Die Schweizerische Post compte actuellement 170 postes ouverts publiés sur Frontaliere Ticino, répartis dans 6 cantons suisses. Le canton de BE compte le plus grand nombre d’offres (31), suivi de ZH (29), AG (19), LU (16), SO (14), GR (12). Par ville, les sites avec le plus de postes ouverts sont Bern (14 offres), suivi de Zürich (11), Härkingen (10), Basel (6), Schaffhausen (4), Wädenswil (4). Le salaire médian estimé pour ces postes est de CHF 72'250 brut par an. Au cours des 28 derniers jours, 645 nouvelles annonces ont été publiées. Les salaires publiés pour ces postes vont de CHF 48'000 à CHF 143'000 brut par an. Parcourez les postes actifs ci-dessous et postulez directement sur le site de l’employeur.
